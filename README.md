# נוטפאד S Pen

נוטפאד לכתיבה ביד בעט S Pen, ל-Galaxy S25 Ultra ולכל מכשיר עם עט או מסך מגע. האפליקציה רצה בדפדפן, ואפשר להתקין אותה במסך הבית ולהשתמש בה גם בלי אינטרנט.

## מה יש באפליקציה

- **כתיבה:** כתיבה בהשהיה נמוכה, עובי קו לפי לחץ, קו חלק ודחיית כף יד.
- **מחיקה:** מחזיקים את כפתור העט ומוחקים, או בוחרים מצב מתג. אפשר למחוק קו שלם או רק חלק ממנו.
- **כלים:** עט, מרקר ומחק, כל אחד בהקשה אחת. 4 צבעים לעט ו-4 צבעים למרקר.
- **נייר:** חלק, שורות או משובץ. זום בצביטה, והדף ממשיך שמאלה כשכותבים ליד הקצה.
- **שמירה:** כ-PDF, וגם נעילת פתק בסיסמה לעריכה.
- **שמירה אוטומטית:** הפתקים נשמרים בדפדפן של המכשיר בלבד.

## העלאה ל-GitHub Pages

### דרך האתר, בלי פקודות

1. ב-GitHub לוחצים על **New repository**, נותנים שם (למשל `spen-notepad`), בוחרים **Public** ויוצרים את המאגר.
2. לוחצים על **uploading an existing file** וגוררים את **כל** הקבצים מהתיקייה הזו, כולל התיקיות `icons` ו-`.github`.
   > את התיקייה `.github` לפעמים לא רואים, כי היא מוסתרת. אם היא לא עולה, אפשר לדלג על שלב 3 ולהשתמש בשלב 3א.
3. **Settings → Pages**, ותחת **Source** בוחרים **GitHub Actions**. הפרסום רץ אוטומטית בכל שינוי.
   - **3א, אם `.github` לא עלתה:** תחת **Source** בוחרים **Deploy from a branch**, ואז את הענף `main` ואת התיקייה `/ (root)`.
4. אחרי דקה או שתיים האתר זמין בכתובת:
   `https://<שם-המשתמש>.github.io/spen-notepad/`

### דרך שורת הפקודה

```bash
cd spen-notepad
git init -b main
git add .
git commit -m "נוטפאד S Pen"
git remote add origin https://github.com/<שם-המשתמש>/spen-notepad.git
git push -u origin main
```

אחרי ה-push מגדירים פעם אחת: **Settings → Pages → Source: GitHub Actions**.

## התקנה בטלפון

1. פותחים את הכתובת ב-**Chrome** בטלפון.
2. בתפריט ⋮ בוחרים **התקנת אפליקציה** (או **הוספה למסך הבית**).
3. האפליקציה נפתחת במסך מלא מהאייקון ועובדת גם בלי אינטרנט.

## עדכון גרסה

1. מחליפים את `index.html` בגרסה החדשה.
2. ב-`sw.js` מעלים את המספר בשורה `const VERSION = 'spen-notepad-v1'`, למשל ל-`v2`. בלי השינוי הזה, טלפונים שכבר התקינו את האפליקציה עלולים להמשיך להציג את הגרסה הישנה.

## חשוב לדעת

- **המרה לטקסט:** Claude ממיר את כתב היד לטקסט, ולכן ההמרה עובדת רק כשהאפליקציה פתוחה בתוך Claude. ב-GitHub Pages זמינה השמירה כ-PDF, ובמקום המרה לטקסט מופיע הסבר.
- **איפה נשמרים הפתקים:** בדפדפן של המכשיר בלבד, ולכל כתובת יש אחסון משלה. פתקים שנכתבו בגרסה שבתוך Claude לא יופיעו בגרסה שב-GitHub. כדי להעביר פתק, משתמשים ב-**הגדרות → גיבוי הפתק**.
- **הסיסמה** מונעת עריכה באפליקציה, אבל לא מצפינה את הפתק.
- **מחיקת נתוני האתר** בהגדרות של Chrome מוחקת גם את הפתקים. לפני כן כדאי לשמור את הפתקים החשובים כ-PDF.

## מבנה הקבצים

| קובץ | תפקיד |
|---|---|
| `index.html` | כל האפליקציה (קובץ אחד, בלי ספריות חיצוניות) |
| `manifest.webmanifest` | שם, אייקונים ומסך מלא להתקנה |
| `sw.js` | שמירת הקבצים במטמון לעבודה בלי אינטרנט |
| `icons/` | אייקונים 192 ו-512, כולל גרסה ל-Android (maskable) |
| `.github/workflows/pages.yml` | פרסום אוטומטי ל-GitHub Pages |
| `.nojekyll` | מבטל עיבוד Jekyll מיותר |
